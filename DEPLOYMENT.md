# Deploying Suvidha Travels to Vercel

## Prerequisites
- Git installed on your machine
- GitHub account with the repository pushed
- Vercel account (free at https://vercel.com)

## Step-by-Step Deployment Guide

### 1. Initialize Git (if not already done)
```powershell
cd "d:\study\WEB DEV\HTML\suvidha"
git init
git add .
git commit -m "Initial commit: Suvidha Travels website with Babel compilation"
```

### 2. Push to GitHub
```powershell
# Create a new repository on GitHub (https://github.com/new)
# Then push your code:

git remote add origin https://github.com/YOUR_USERNAME/suvidha.git
git branch -M main
git push -u origin main
```

### 3. Deploy to Vercel

**Option A: Using Vercel CLI (Recommended)**

1. Install Vercel CLI:
```powershell
npm install -g vercel
```

2. Login to Vercel:
```powershell
vercel login
```

3. Deploy your project:
```powershell
vercel
```

4. Follow the prompts:
   - Link to existing project? → No
   - Set project name → `suvidha-travels` (or your choice)
   - Select scope → Your username
   - Set root directory → ./ (leave as default)
   - Modify settings? → No
   - Deploy? → Yes

**Option B: Using Vercel Web Dashboard**

1. Go to https://vercel.com/new
2. Select "Import Git Repository"
3. Paste your GitHub repository URL
4. Click Import
5. Configure build settings:
   - **Framework**: Other (static site)
   - **Build Command**: `npm run build:js`
   - **Output Directory**: (leave empty)
   - **Environment Variables**: (none needed for this project)
6. Click "Deploy"

### 4. Verify Deployment

After deployment, Vercel will provide you with:
- **Production URL**: `https://your-project.vercel.app`
- **Git integrations**: Auto-deploy on every push to main branch

Test your deployed site:
- Home page: `https://your-project.vercel.app/index.html` or `https://your-project.vercel.app`
- Destination pages: `https://your-project.vercel.app/pages.html?destination=dubai`

## Key Files for Vercel Deployment

### vercel.json
Configures build and output settings for Vercel:
- `buildCommand`: Runs `npm run build:js` to compile JSX to ES5
- `outputDirectory`: Serves files from root (.)

### package.json Updates
- Added `"build"` script that runs Babel compilation
- All dependencies are in `devDependencies` (no runtime dependencies except React from CDN)

## Environment Setup

Your project uses:
- **React 18** (from CDN - no installation needed)
- **Tailwind CSS** (from CDN - no installation needed)
- **Babel CLI** (for JSX compilation)
- **ES6+ syntax** (transpiled to ES5 for browser compatibility)

## Build Process

When Vercel deploys:
1. Installs dependencies from `package.json`
2. Runs `npm run build:js` which executes: `babel src --out-dir dist`
3. Converts JSX files to standard JavaScript:
   - `src/main.js` → `dist/main.js`
   - `src/pages-app.js` → `dist/pages-app.js`
4. Serves static files (HTML, CSS, compiled JS, images, videos)

## Continuous Deployment

Once deployed:
- Every push to `main` branch automatically redeploys
- No need to manually deploy again
- Vercel shows deployment status on push

## Custom Domain (Optional)

To use a custom domain like `suvidhatravels.com`:
1. Go to project settings on Vercel dashboard
2. Navigate to "Domains"
3. Add your domain
4. Update DNS records with Vercel's nameservers
5. Vercel automatically provisions SSL certificate

## Troubleshooting

### Build fails with "Babel not found"
- Ensure `@babel/cli` is in devDependencies
- Run `npm install` locally to update package-lock.json
- Push changes to GitHub and retry deployment

### Pages not loading
- Check that `dist/main.js` and `dist/pages-app.js` exist
- Verify script src paths in HTML match output location
- Check browser console for JavaScript errors

### SEO issues
- robots.txt and sitemap.xml are served as static files
- Meta tags in HTML are served correctly
- Use Vercel Analytics to monitor SEO performance
